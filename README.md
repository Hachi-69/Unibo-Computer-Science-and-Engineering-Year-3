# Unibo Computer Science - Year 3 Projects

This repository contains my projects, assignments, and exercises from the third year of the Computer Science and Engineering program at the University of Bologna (UNIBO).

## Courses & Projects

### 1. Software Engineering
* **Description:** Projects and exercises focused on software development methodologies, lifecycle models, and architectural design.
* **Topics:** Agile methodologies (Scrum), requirements engineering, UML, software testing (unit, integration), CI/CD pipelines, and software maintenance.
* **Repository Folder:** `Software-Engineering`

### 2. Telecommunication Networks
* **Description:** Assignments and projects exploring network architectures, communication protocols, and the fundamental principles of data transmission.
* **Topics:** OSI and TCP/IP models, routing algorithms, transport layer protocols (TCP/UDP), application layer protocols (HTTP, DNS), and socket programming.
* **Repository Folder:** `Telecommunication-Networks`

### 3. Web Technologies
* **Description:** Projects focused on modern web application development, covering both client-side and server-side paradigms.
* **Topics:** HTML, CSS, JavaScript, frontend frameworks (e.g., React, Vue, or Angular), backend development (e.g., Node.js), RESTful APIs, and basic web security.
* **Repository Folder:** `Web-Technologies`

### 4. Advanced Databases
* **Description:** Projects and exercises diving deeper into complex database systems, non-relational models, and advanced data management.
* **Topics:** Distributed databases, NoSQL systems (document, graph, and key-value stores), query optimization, data warehousing, and big data concepts.
* **Repository Folder:** `Advanced-Databases`

### 5. Mobile Systems Programming
* **Description:** Assignments and implementations of mobile applications for modern smart devices.
* **Topics:** Native and cross-platform mobile development (Android/iOS), mobile UI/UX design, sensor integration, local storage, and background processing.
* **Repository Folder:** `Mobile-Systems-Programming`

### 6. Cryptography
* **Description:** Projects exploring the mathematical foundations and practical implementations of cryptographic protocols to secure data.
* **Topics:** Symmetric and asymmetric encryption (AES, RSA), cryptographic hashing, digital signatures, public key infrastructure (PKI), and secure communication protocols.
* **Repository Folder:** `Cryptography`

### 7. Virtualization and System Integration
* **Description:** Projects focusing on virtualization technologies, containerization, and integrating diverse software systems.
* **Topics:** Virtual machines, hypervisors, containerization (Docker, Kubernetes), cloud computing models, microservices architecture, and infrastructure as code (IaC).
* **Repository Folder:** `Virtualization-and-System-Integration`
