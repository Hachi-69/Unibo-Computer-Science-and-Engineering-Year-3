# Laboratorio Tailwind CSS · TW Day 2027

Tecnologie Web 2026/2027

In questo laboratorio costruisci, un pezzo alla volta, il sito di **TW Day 2027**, «la giornata dei progetti di Tecnologie Web», con Tailwind CSS v4.

## Come aprire un esercizio

- Fai doppio clic su `index.html`: la pagina si apre nel browser. Dopo ogni modifica, salva e ricarica.
- Oppure apri la cartella in VS Code e usa l'estensione **Live Server**, che ricarica la pagina da sola a ogni salvataggio.
- Tailwind arriva dal CDN: serve la **connessione a internet**.

## Dove sta la consegna

Nella slide dell'esercizio e nel commento in cima a `index.html`. I commenti `TODO` segnano i punti in cui intervenire e hanno lo stesso numero del passo della consegna.

## Le cartelle sono indipendenti

Ogni esercizio funziona da solo: se resti indietro, apri direttamente l'esercizio successivo.

## DevTools

- **F12**: apre i DevTools, per ispezionare elementi e classi. Gli errori compaiono nella scheda Console.
- **Ctrl+Shift+M** (con i DevTools aperti): vista da telefono.
- Su Mac: **Cmd+Option+I** e **Cmd+Shift+M**.
